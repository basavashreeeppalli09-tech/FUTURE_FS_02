📊 Client Lead Management System

A simple and responsive web application to manage client leads, track communication status, and organize potential customers.

🌟 Features

- 📈 Dashboard with lead statistics
- ➕ Add new clients
- 🔍 Search clients by name, phone, email, or interest
- 🏷️ Filter clients by status
- ✏️ Edit client details
- 🗑️ Delete client records
- 💾 Save data using browser local storage
- 📱 Responsive design for mobile and desktop

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
